# 百面相当前产品范围

本文描述0.1.0-alpha.59当前产品范围；实际安装和当前授权以私有memory及安装清单为准。

视页保留全人物选择、简短身份与局部图，不设人物档案入口；听页展示场外事务（含已完成）及其最新有效自创进展；只排除参与人非空且全部明确在场的卡片，混合事务保留完整参与者，空或未知参与者不猜测排除；原活动和正文事实保留在世界中，最近经历暂不显示。嗅页公开信息暂为空，味页持续圈层背景；设置保留全部连接、共享池与外观能力。暂不展示经历不改变经历的生成、保存与后续承接，QQJ原资料与回忆仍按原合同读取。持续事务按planned/active/waiting/completed承接打算、正在做的事和明确等待条件；事件仅为已发生结果，人物知情须有途径，未来计划不提前写成事实，不替故事user行动或答复。

发展是共同创作人物镜头外的生活。听觉以实际场外人物的日常为首要取材，在场正文可校准为已知约束，不代替场外创作；同一实际事项沿旧ID，不因视角、称谓或参与者子集另建。正文提供时间与事实边界，不是幕后行动的许可清单；模型结合职责、兴趣、关系和已有结果作选择并落实后果，事务完成后可以自然开展下一项。真实休息或等待应来自人物安排、选择或实际限制，不能仅以“正文未写行动”作为平静理由，也不要求每人每轮必须有事件。

设置提供两个真实世界入口。世界构建一次重读许可卡书、人物与稳定正文，重新核对自动人物与重叠社交群/明确关系，不要求新增剧情。同一圈沿旧ID，有据不适用的自动圈可结束后重分组；人工和经历保留，不补演空档，保留原自动资格。未启用档构建后等待手动流转；已启用档构建与重存结束后等待新的稳定剧情，不立即追加味听，也不在下个新楼事件重复旧基线。已处理旧正文只作参考，不回退当前时钟、事务、在场或处理位置。新卡已有确认聊天身份及静态资料时可先构筑，无稳定正文不造楼号或时间，最新AI仍排除。首次直接百相流转缺底账时自动构筑并等保存ACK，再味→保存→听，共3次；已有底账后每轮2次，听成功保存才开启自动流转；旧底账缺人或尚未对照许可书时在味同答静态补齐，听在保存后立即接新名单。推进同答维护群与关系、事件承接/因果引用，按关联选取记忆但保存完整世界；同圈不自动知情。每N个正式新AI回复处理积累正文，含user与QQJ隐藏有效正文；设置变更不立即发请求，无新正文不重复生成。

世界观标题与两个按钮之间用一行小字显示实际流转状态：正常待启用、等待与工作中为绿，失败、停止或待重存等需处理状态为橙，并沿用已有入口提示可执行操作。显示基于当前真实配置、world与任务状态，不新增开关、灯点、健康请求、持久恢复或轮询。

总开关及版本更新直接沿用千千结交互；通用设置沿用其完整世界书排除、破限提示词及正文包裹符逻辑，外观保留百面相。API布局保留并配蓝色，内容设置仅保留几楼一更新。视页不再重复图中事务，听页状态前置、最新进展直接可见，听/味页不重复全局发展入口；人物抽屉用同蓝色与短滑入动效。

请求中到达的新楼在ACK后承接；失败/停止暂停，不自动重发。已有候选保存失败不重发该模块；情绪候选重存成功再继续尚未派发事务，事务候选重存为零模型。真实冲突明确重读。现有设置/窗口/输入隔离保留，主楼回流后置。局部图只展示明确关系、分型事务与圈层，不从同圈/共事推朋友；不显示内部来源/方案审查或预算选择。

程序只解析确定归属、保护人工/正文并可靠保存，模型判断时间与生活语义。过去事件只采用显式activityChange，不以段末概况反填；完整原内容不被新摘要覆盖。离线协议、真实模型连续承接与安卓实机分开验收，测试通过不授权发布。

味以已存有效群和明确关系为取材单位，保重叠成员与各自差异。完整正文单列变化依据，基础和旧底色作主体；听仍从个人事务、职责、承诺和实际结果出发。共享材料准备一次，不为各圈新增调用。

味的已知长期背景与本批新增偏移在同答分段接纳，界面与存档仍为单条圈层风向；不从旧自由文猜拆，不用程序关键词判断语义。听保留原状态/事务与人物回链，以最新实际进展或概况形成一段阅读重点。

味页标题静态展示；短简介直接完整显示且没有三角或展开操作，只有真实超过两行的长文才在Plasma下方简介提供收展，收起两行并为右下三角留出空隙，展开阅读同一完整原文，人物回链独立。实际排版随宽度、字号、字体和内容变化更新判断。人物图中的事务入口与听页可见规则一致，避免出现没有目标的跳转。

圈层先辨明确关系，再按共同工作/生活/长期往来的真实纽带归纳，允许未命名但有稳定共同事由的圈、重叠成员及独立两人关系。普通味沿旧id完善粗群说明，检查有据成员/关系/新圈/结束，只返回新增或实变；既有有效事件可作已知背景，静态源不能绕过显式新增断言。听从本轮真正接纳事件维护社会变化，下一味承接，仍原2次请求。

事务生成标题最多12字，过程和结果放简介；长回答仍完整保存，听页单行省略并保完整标题。API模型列表紧凑小字，底部四动作按内容自然宽度排列。

味卡以有效foundation群为稳定主体，标题与成员来自当前群；无风向也显示群说明。关系只在有明确归属风向时补卡，多个同圈风向保全部正文，不统一成员情绪。circleRef为可选正式外键，旧唯一已接纳G/R依据可恢复；新无主体或多主体风向不存，旧scene保待同次正常味修正。UI全群成员与听/检索的原风向受影响范围分开。听正文仅派生补末标点；同事项旧ID由模型语义续用，程序无模糊去重。图谱密度与手动编辑后置。
