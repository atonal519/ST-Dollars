# ST-Dollars 人物世界骨架

这是 ST-Dollars 的人物世界重写分支，当前版本为 `0.1.0-alpha.1`。它提供一个可从 SillyTavern 或 Luker 扩展菜单打开的前端骨架：空世界页面、人物与活动图谱投影、节点详情界面、设置说明和简化业务类型。

## 当前能做什么

- 从宿主扩展菜单打开或关闭人物世界面板。
- 展示由 `WorldSnapshot` 投影出的 SVG 人物/活动节点和明确的“参与”连线；选择节点后从同一业务快照展示详情。
- 保留人物、活动、事件、知情、剧情时间与来源的 TypeScript 合同。

默认状态是空世界：没有绑定真实聊天、人物或剧情时间，也不会创建演示活动。图谱不是第二份事实存储，连线只从活动上明确给出的参与者 ID 投影。

## 当前尚未接入

本分支不读取或保存真实聊天、角色卡、世界书、千千结或白鳥数据；不调用模型、不推演人物、不做主楼输入/回流、不迁移旧存档。人物资料、模型、持久化和主楼边界目前只有小型接口合同。界面如实说明这些功能尚未接入。

图谱当前仅为小规模 SVG 骨架，没有拖动、缩放、搜索或大图性能承诺。模型请求的具体编排也尚未决定。

## 数据与故事规则

本插件未来拥有自身的人物活动、已发生事件和知情记录；原始人物资料仍归其来源。所有人物使用同一类型，不区分 char/NPC 或主配角。玩家是故事外的全知观察者；作者能看到记录不会令故事人物自动知情。剧情时间只保留故事提供的表达，不换算现实时间。计划中的活动、进行中的活动与已发生结果分别表达；不代替故事中的 user 回应，也不改写正文事实。

## 开发

工作区沿用正式 Dollars 已安装的 Vue、Vite 和 TypeScript 版本，不需要服务端插件。

```sh
pnpm test
pnpm run typecheck
pnpm build
```

`dist/` 是可由插件 manifest 加载的前端产物。常规前端修改在页面刷新后生效，不要求重启酒馆。

架构与模块边界见 [docs/architecture.md](docs/architecture.md)。
