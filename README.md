# 百面相（Polyphony）

这是 ST-Dollars 人物世界项目的重写分支，云端仓库名为 `ST-Polyphony`，当前版本为 `0.1.0-alpha.11`。它提供可从 SillyTavern 或 Luker 扩展菜单打开的百面相窗口、人物图谱与手动剧情推进；本地数据标识继续沿用原有名称。

产品方向与当前、后续范围见[产品设计](docs/design.md)；模块和依赖边界见[架构说明](docs/architecture.md)。

## 当前能做什么

- 从宿主扩展菜单打开或关闭人物世界面板。
- 打开面板时通过千千结正式只读接口 `getPeopleSnapshot()` 读取一次已确认人物目录；点击“刷新人物”可再次读取。
- 展示从统一 `WorldSnapshot` 派生的 SVG 人物与活动图谱；人物与活动只按明确参与 ID 相连，不从同名、位置或共同活动推断关系。图上人物名最多显示前三个 Unicode 字符，较长名字以省略号结尾；完整姓名仍显示在手机概况和资料页。无活动人物按稳定 ID 确定性错落排位，缩放工具行位于绘图区上方。
- 手机点选后先保留图谱并显示短概况，再进入完整资料；桌面点选直接进入完整资料。完整阅读有固定返回入口，长档案在独立滚动区内显示。
- 打开人物详情时通过千千结正式 `readContext()` 读取该人物已加载的当前状态与相关经历；“刷新相关资料”可再次读取。人物资料没有档案正文也能展示状态和经历。
- 图谱、手机概况和完整阅读位于同一 Shadow DOM 窗口；设置与关闭入口也在窗口内。人物概况分别标注最近发生的事件和此人已知的事件。
- 目录为空、千千结未启用、尚在等待或读取失败时显示对应说明。首楼尚未稳定、人物记录尚未开始属于正常等待。
- 保留人物、活动、事件、知情、剧情时间与来源的 TypeScript 合同。
- “推进到当前剧情”读取自上次处理位置之后的已完成正文；第一次以最新完成的 AI 楼作为起点。正常每批调用一次副模型确定范围、一次主模型批量推演；明确无人参与时只调用一次。模型不自动重试。
- assistant 楼进入资料查询与推演前会删除完整配对的 `[DRAFT]...[/DRAFT]` 内容；唯一完整的 `<content>...</content>` 作为正式正文，外围评论不进入剧情。无法明确选出唯一 content 时只删除完整 DRAFT 块并保留其余文本。已识别的前缀日期/时间/星期与楼内标准时间标记作为参考保留；user 楼不清洗。
- 百面相的活动、事件、知情和处理位置保存于独立白鸟世界记录；打开面板和刷新人物时加载该记录并从当前千千结目录派生图谱，不复制人物资料。
- 设置页可为 Primary/Secondary 选择独立 API，或引用构画持有、千千结共享使用的 API 池预设；共享连接按 ID 即时读取，白鸟只保存预设引用，不复制共享 URL、Key 或模型名。Key 仅在请求时使用，界面只显示保存状态；独立配置留空保存会保留原 Key。所有模型请求经酒馆现有 chat-completions 接口。
- 外观支持“跟随酒馆 / 日间 / 夜间”。跟随模式读取酒馆主题颜色信号并映射到百面相自己的颜色变量；主题设置保存在酒馆的 Dollars 扩展设置中。
- 活动节点以中文显示状态；活动详情只展示明确关联到该活动的已发生结果。知情记录独立显示人物、事件和原因。

QQJ 人物目录是唯一人物来源；ID 由 QQJ 聊天身份和实体 ID 组成，不按显示名合并。`selected` 和是否有档案正文都不会作为入图条件。目录快照只在打开和手动刷新时读取；状态与经历只在查看人物或手动刷新资料时读取，不轮询。原始档案、状态和经历仍归千千结，本插件不保存副本。玩家可查看作者侧资料，但这不会令故事人物自动知情。

## 当前范围

后续主页方向已初步确定为当前活动、图谱、公告、设置；当前仍只交付图谱页、人物概况与资料阅读及设置，尚未实现新增页面。自动推进、主楼回流及其他人物资料来源尚未实现。虚构人物起步样例此前已通过真实调用与隔离保存/读取验收；真实卡/长线语义仍待实测。

图谱使用轻量响应式 SVG，布局随稳定 ID 保持一致；长图谱可平移浏览。无活动人物仍以错落星点呈现，位置不代表关系；选取或拖动不会改动人物事实。当前没有搜索功能或超大目录性能承诺。QQJ 单次资料读取上限为100人；超过限制会停止本轮并给出提示，不会静默拆分。

## 数据与故事规则

本插件拥有自身的人物活动、已发生事件和知情记录；原始人物资料仍归其来源。所有人物使用同一类型，不区分 char/NPC 或主配角。玩家是故事外的全知观察者；作者能看到记录不会令故事人物自动知情。剧情时间只保留模型依据正文明确判断的表达，不换算现实时间。计划中的活动、进行中的活动与已发生结果分别表达；不代替故事中的 user 回应，也不改写正文事实。

## 开发

运行时依赖千千结正式公共桥读取人物与资料、白鸟 records 接口保存百面相自己的世界记录，并通过酒馆现有 chat-completions 接口请求配置的模型。共享 API 池由构画持有并供千千结共享使用；百面相只按引用读取，不管理共享连接。当前不需要新增服务端插件；前端常规更新在页面刷新后生效。

```sh
pnpm test
pnpm run typecheck
pnpm build
```

`dist/` 是可由插件 manifest 加载的前端产物。常规前端修改在页面刷新后生效，不要求重启酒馆。
