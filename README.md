# 百面相（Polyphony）

百面相从千千结读取人物资料，并承接镜头外的群像生活。手机界面按视、听、嗅、味与设置组织。视页采用右侧覆盖人物抽屉与可沿边拖动的局部玻璃入口，位置仅当前界面内存；听页为直接阅读的场外事务清单，味页为已有稳定社交群及其风向清单，窗口暂用固定蓝绿圆斑薄玻璃。

本文描述 `0.1.0-alpha.59` 当前本地源码；实际安装状态以清单为准。实际安装资源见[安装清单](/home/admin/sillytavern/data/codex-private/baimian-trajectory-20261021/latest-deployment.json)，当前授权与待办见[私有 memory](/home/admin/sillytavern/data/codex-private/baimian-trajectory-20261021/memory.md)。开发入口见 [AGENTS.md](AGENTS.md) 与 [agent.md](agent.md)。

## 当前界面与人物发展

视页可选择全部人物，显示简短身份及局部图，图中分开表达明确人际关系、参与事务和情绪圈层。听页展示场外事务（含已完成），只排除参与者非空且全部明确在场的卡片；混合事务保留完整参与者，空或未知参与者不猜测排除。人物图中的事务入口与听页可见清单一致，标题单行省略但完整内容保留，状态前置，有最新有效自创进展便以其为完整主正文，没有则显示事务概况，人物导航居后；嗅页目前为空，味页持续展示有效群名、当前在群成员及32px高全宽Plasma横幅；没有风向时显示已知群说明，有明确归属的风向时显示其全部正文，直接关系仅在已有归属风向时补卡，标题静态展示，短简介直接完整显示，只有真实超过两行的长文才显示三角并可点击展开、收起同一完整原文。经历的生成、保存与后续承接保持，QQJ原资料与回忆仍按原合同读取。

设置的“世界构建”可随时重整人物与社交基础，不依赖新增剧情：一次主模型重读完整许可卡书、必要QQJ字段与稳定正文，重新核对自动人物、群与关系。同一圈保原ID，有据不适用的自动圈可结束后重新分组，保留已有经历、知情和人工内容，不补演空档。构建保留当前聊天原有自动流转资格；未启用档仍需点击“百相流转”，已启用档构建或重存后等待后续稳定剧情，不立即追加味、听请求。较早已处理正文只作参考，不回退当前时钟、事务或处理位置。已有确认聊天身份与卡书资料的新卡暂无稳定正文时，也可先构筑静态基础；最新AI仍排除。“百相流转”先一次主模型形成局部风向并保存，再一次主模型读取实际保存结果，发展事务、经历和知情；听的结果成功保存后开启此聊天自动发展。构建后手动首次流转处理同一基线当前时点；已启用档收到新的稳定楼时沿原处理位置累计，达到N后只做原一轮味、听。可直接点流转；缺基础时会自动补这唯一一次构筑，已有基础后仍为两次。

世界观标题下、两个操作按钮上方显示一行状态：正常待启用、等待和工作中为绿色，需要处理的失败或暂停为橙色。状态复用当前配置、已保存世界及真实进度；失败、停止和待重存会说明可继续操作的原因，不增加开关、健康检查请求或后台轮询。

内容设置“几楼一更新”默认1；按正式新AI正文累计，输入包含其间user正文，达到N以同批关联资料完成味与听两模块；首次缺基础时先独立构筑并保存，共3次，已有底账后2次。百相流转可在未满N时提前处理。安装、开面板、旧启用设置或旧启动标记不会发模型；新聊天正文/QQJ身份未起步正常等待。

请求期间新楼留到成功保存后按最新N检查。停止或失败暂停自动推进；保存失败可重存同候选，不重发该模块，风向重存成功后继续尚未派发的人物发展。风向已保存而人物发展失败或停止时，下次明确操作只续剩余模块；真实冲突不盲写。每次派发取百面相最新主配置，未使用副模型不作门槛。人物事件只记录已发生结果，未来意图保留为持续事务；主聊天回流尚未接通。

设置直接移植千千结总开关、版本更新、世界书排除及提示词/包裹符交互；API保留百面相布局并使用蓝色。通用设置除外观外共用白鳥设置，世界书排除先于读取生效，正文按共享包裹符清洗。破限提示词使用`schedule-planner.processingPrompt`，每次实际文字请求读取；留空使用内置默认；恢复默认清空草稿，保存后生效，载入内置默认仅把全文填入草稿。原草稿、取消与保存交互保持。桌面窗口可拖动顶栏空白、拖动右下角调整大小，位置与尺寸作为百面相独立本地UI偏好保存；手机布局保持。固定蓝壳暂不随原主题模式换配方；原主题get/save继续有效。窗口沿既有Shadow DOM隔离，内部依据与历史工作台不显示。

## 数据与边界

正常加载、完成回调、未派发原因、模型原答/错误、解码/应用与保存回应会在插件专用白鳥记录 `st-dollars / diagnostics-development / recent` 有界留证，可由后台直接读取。两模块分别保留原答并关联同批操作。保留最近12次触发或操作（含挂载、跳过及保存后检查），24小时窗口在新事件时裁剪；单份原答最多256KiB、原答合计512KiB、整份记录最多640KiB，截断明确标注。凭证、完整设置、输入正文和人物档案不写诊断；诊断失败不影响业务结果、不自动重试，没有常驻采集或额外模型调用。诊断记录不代替权威世界，也不能还原安装前已丢失的日志。

人物目录合并千千结公共桥与本world的最小人物底账，包含世界书明确但尚未出场的人物；不复制QQJ整份档案/NSFW栏目。百面相世界仍保存在白鸟 `st-dollars / npc-world-{QQJChatId} / world`。姓名、事件、时间和正文均使用原记录；无内容不补写人设或当前动作。世界处理楼号、旧活动状态或数组追加位置不能当人物实时状态。

模型设置仍独立于主聊天；原配置消费者和保存功能保持。仅阅读已有记录不发模型或写世界；设置中显式测试等既有动作仍按用户操作执行。新增分类尚未做真实模型质量与安卓实机验收。
